# The Game of Peace: 구울 증후군

중세 왕국 세계관 위에 좀비 아포칼립스(구울 증후군)를 얹은 **3세력 국가 운영 웹게임**입니다.
Reigns식 선택지 카드 + TRPG식 **5d20 주사위 판정**. 1턴 = 3개월, 총 40턴(10년), 시작은 여신력 759년 봄.

- **아르칸달 군국** — 철벽의 방벽망으로 대륙을 봉쇄 (승리: 방벽 100 + 감염도 20 미만)
- **아이루스 공국** — 황금 저울과 빙철로 치료제를 완성 (승리: 공유 연구 100)
- **구울 부두교** — 구울을 은총으로 여기고 대륙을 감염 (승리: 대륙 감염 진척 CI 85를 2턴 연속)

부두교가 승리하면 다른 두 세력은 함께 패배하고, 아르칸달·아이루스가 이기면 부두교가 패배합니다.

## 실행 방법

```bash
pnpm install
pnpm gen          # 5d20 분포표(CDF) 생성 → packages/engine/src/generated
pnpm test         # 엔진 유닛 테스트 + 카드 검증 + 40턴 자동 플레이
pnpm dev          # 개발 서버 (apps/web)
```

- 게임: `/` (`index.html`)
- 5d20 주사위 단독 데모: `/dice.html`
- 일러스트 갤러리: `/art.html`

빌드:

```bash
pnpm build         # 정적 호스팅용 멀티 페이지 (apps/web/dist) — Vercel/Cloudflare Pages
pnpm build:single  # 단일 HTML 파일 (apps/web/dist-single/index.html)
pnpm sim 1000      # 밸런스 시뮬레이션: 세력당 1000회 자동 플레이
```

## 저장소 구조 (pnpm 모노레포, TypeScript strict)

| 패키지 | 역할 |
|---|---|
| `packages/engine` | 순수 규칙 엔진. 브라우저 의존 없음. `resolveChoice(state, card, choice, rng)`, `startTurn`/`endTurn` 등은 입력 state를 바꾸지 않고 새 state를 돌려줍니다. 5d20 CDF·등급·배율은 `src/data/grades.json`과 빌드 시 생성되는 `src/generated/cdf5d20.ts`에 분리. |
| `packages/content` | 카드 JSON(`cards/content.json`) + zod 스키마 검증. 세력별 40장 + 공통 40장 + 상황/붕괴/고정 사건. |
| `apps/web` | React + Vite + Zustand + Tailwind. 대시보드·카드·5d20 주사위 연출·연대기·엔딩. IndexedDB 저장(`idb-keyval`). |
| `scripts/sim.ts` | 밸런스 시뮬레이션. |

엔진이 순수 함수로 분리돼 있어, 나중에 `apps/server`를 붙여 서버 권한 판정으로 옮겨도 규칙이 달라지지 않습니다.

## 주사위 판정 (5d20)

20면체 5개를 굴려 합(5~100)에 보정(능력치 (게이지−50)÷5 + 선택지 난이도 + 상태)을 더합니다.
합의 분포가 종 모양이라, **빌드 시 5d20 합의 CDF 표를 계산**해 두고 최종값을 백분위 rank(1~100)로 바꿔 효과 배율(0.30~1.60, 앵커 선형 보간)을 정합니다.
이로운 효과는 배율만큼 커지고, 해로운 효과는 잘 나올수록 줄며, 자원 비용은 고정입니다. 최종값 40 미만이면 `onFail` 비용이 더해지고, 17 이하면 후유증 카드가 나옵니다.

**난수는 시드 고정 RNG(mulberry32)로 애니메이션 전에 확정**하고 `state.rng`에 저장합니다. 화면 연출은 이미 정해진 결과를 보여 줄 뿐이라 같은 시드는 끝까지 같은 게임이 됩니다(리플레이 가능). `pnpm test`의 "같은 시드 리플레이" 테스트가 이를 검증합니다.

## 밸런스 (세력당 1000회 자동 플레이, 휴리스틱 정책)

| 세력 | 승률 | 평균 턴 |
|---|---|---|
| 아르칸달 | 41.8% | 9.0 |
| 아이루스 | 42.6% | 32.4 |
| 부두교 | 41.0% | 29.3 |

목표였던 30~45% 승률 안에 세 세력 모두 들어옵니다. 자동 플레이는 "그럭저럭 합리적인" 봇이라, 사람이 직접 하면 결과가 달라질 수 있습니다. 아르칸달은 초반 민심 붕괴가 잦은 고위험 세력으로 설계됐습니다.

## 가정 (기획서에 없어 제가 정한 결정)

- **능력치 보정** = (게이지 − 50) ÷ 5 (−10 ~ +10).
- **은닉(부두교)** 은 높을수록 안전한 게이지이며, 0이 되면 대토벌로 패배합니다.
- **효과 배율** 적용 규칙: 이로운 효과 ×배율, 해로운 효과 ×(2−배율)[0.4~1.7], 자원 비용(실링·전략 자원·식량·먹이 감소)은 고정, 부두교 확산 행동의 은닉 대가는 `withSuccess`로 성공할수록 더 깎입니다.
- **공통 카드 게이지 매핑**: 부두교에서 민심/질서/재정/정통성 → 신앙/제어/제물/은닉(정통성↔은닉은 부호 반전).
- **인구 손실 지연**: 잠복 1턴 → 발병 1턴 → 구울화. 인구 손실은 2계절 전 감염도를 기준으로 계산합니다.
- **기본 확산** = 1.5 + 감염도×0.04 (아르칸달 +1 후 방벽으로 감소, 부두교 제어<40 +2, 중립지는 별도 공식).
- **중립지(라벤 폐허 포함)** 감염도 시작 40. CI = (아르칸달 + 아이루스 + 중립지) ÷ 3.
- **진노 단계** 30/60/90/100 → 생산 ×0.95/0.85/0.7/0.5, 100은 모든 판정 −5이며 되돌릴 수 없음.
- **동맹**: 관계 80에서 체결(부두교는 구울 공인 협정). 아르칸달 외교 판정 −10.
- **행동권**: 미사용분을 다음 턴에 이월, 최대 3.
- **AI 부두교**(부두교를 플레이하지 않을 때): 매 턴 세력 규모에 비례해 대상 지역 감염도 +2~4(시간이 갈수록 증가). 플레이어가 부두교면 아르칸달·아이루스 AI가 방벽·연구를 진척시키며 경쟁합니다.
- 카드 데이터는 `author/`의 파이썬 DSL로 초안을 만들고(`content.json` 생성), 밸런스 조정 수치는 `content.json`에 직접 반영했습니다.
- 일러스트는 외부 이미지 없이 인라인 SVG 심볼 33종(기획서의 20종 이상 요건 충족)으로, 세력 2톤 + 금색 포인트의 플랫 벡터입니다.
