# The Game of Peace: 구울 증후군

중세 왕국 세계관 위에 좀비 아포칼립스(구울 증후군)를 얹은 **3세력 국가 운영 웹게임**입니다.
Reigns식 선택지 카드 + TRPG식 **5d20 주사위 판정**. 1턴 = 3개월, 총 40턴(10년), 시작은 여신력 759년 봄.

- **아르칸달 군국** — 철벽의 방벽망으로 대륙을 봉쇄 (승리: 방벽 100 + 감염도 20 미만)
- **아이루스 공국** — 황금 저울과 빙철로 치료제를 완성 (승리: 공유 연구 100)
- **구울 부두교** — 구울을 은총으로 여기고 대륙을 감염 (승리: 대륙 감염 진척 CI 85를 2턴 연속)

부두교가 승리하면 다른 두 세력은 함께 패배하고, 아르칸달·아이루스가 이기면 부두교가 패배합니다.

## 실행 방법

```bash
pnpm install
pnpm gen          # 5d20 분포표(CDF) 생성 → packages/engine/src/generated
pnpm test         # 엔진 유닛 테스트 + 카드 검증 + 40턴 자동 플레이 + 웹 순수 함수 테스트
pnpm typecheck    # 세 패키지 tsc (strict)
pnpm dev          # 개발 서버 (apps/web)
```

- 게임: `/` (`index.html`) — `?seed=123456&d=hard&f=iruth`로 같은 판을 공유할 수 있습니다.
- 5d20 주사위 단독 데모: `/dice.html`
- 일러스트 갤러리: `/art.html`

빌드·밸런스:

```bash
pnpm build         # 정적 호스팅용 멀티 페이지 (apps/web/dist) — Vercel/Cloudflare Pages
pnpm build:single  # 단일 HTML 파일 (apps/web/dist-single/index.html)
pnpm sim 1000      # 밸런스 시뮬레이션: 세력당 1000회 자동 플레이 (보통 난이도)
SIM_DIFFICULTY=hell pnpm sim 1000                       # 난이도별
SIM_FACTION=iruth SIM_DECREES=iru-styx-tithe pnpm sim 300 # 법령 하나의 효과만 측정
```

## 저장소 구조 (pnpm 모노레포, TypeScript strict)

| 패키지 | 역할 |
|---|---|
| `packages/engine` | 순수 규칙 엔진. 브라우저 의존 없음. `resolveChoice(state, card, choice, rng)`, `startTurn`/`endTurn`, `enactDecree` 등은 입력 state를 바꾸지 않고 새 state를 돌려줍니다. 5d20 CDF·등급·배율은 `src/data/grades.json`과 빌드 시 생성되는 `src/generated/cdf5d20.ts`에 분리. |
| `packages/content` | 카드 JSON(`cards/content.json`) + zod 스키마 검증. 세력별 40장 + 공통 41장 + 상황/붕괴/고정 사건 + 행동 + 법령 15개. |
| `apps/web` | React + Vite + Zustand + Tailwind. 대시보드·스와이프 카드·5d20 주사위 연출·확산 지도·연대기·엔딩. IndexedDB 저장(`idb-keyval`). |
| `scripts/sim.ts` | 밸런스 시뮬레이션. |

엔진이 순수 함수로 분리돼 있어, 나중에 `apps/server`를 붙여 서버 권한 판정으로 옮겨도 규칙이 달라지지 않습니다.

## 주사위 판정 (5d20)

20면체 5개를 굴려 합(5~100)에 보정(능력치 (게이지−50)÷5 + 선택지 난이도 + 상태)을 더한 **최종값(1~100)** 이 등급을 정합니다.
합의 분포가 종 모양이라, **빌드 시 5d20 합의 CDF 표를 계산**해 두고 최종값을 백분위 rank(1~100)로 바꿔 효과 배율(0.30~1.60, 앵커 선형 보간)을 정합니다.
이로운 효과는 배율만큼 커지고, 해로운 효과는 잘 나올수록 줄며, 자원 비용은 고정입니다.

- 최종값 **40 미만**(`onFailBelow`)이면 `onFail` 비용이 더해집니다. 화면의 "성공 약 N%"는 40 이상이 나올 확률입니다.
- 최종값 **17 이하**(`aftermathAtOrBelow`)면 다음에 후유증 카드가 나옵니다.

등급은 `grades.json`의 15단계입니다(규칙 시트·온보딩의 표는 이 파일에서 자동 생성되고, 아래 표는 테스트가 grades.json과 대조합니다).

| 최종값 | 등급 | 계열 |
|---|---|---|
| 95~100 | 경이로운 대성공 | 대성공 |
| 89~94 | 대성공 | 대성공 |
| 83~88 | 엄청난 성공 | 대성공 |
| 75~82 | 확실한 성공 | 성공 |
| 70~74 | 성공 | 성공 |
| 60~69 | 미온적인 성공 | 성공 |
| 50~59 | 그래도 성공 | 성공 |
| 45~49 | 애매한 성공 | 애매한 성공 |
| 40~44 | 반쪽자리 성공 | 애매한 성공 |
| 32~39 | 아쉬운 실패 | 실패 (실패 비용) |
| 25~31 | 실패 | 실패 (실패 비용) |
| 18~24 | 뼈아픈 실패 | 실패 (실패 비용) |
| 12~17 | 대실패 | 대실패 (실패 비용 + 후유증) |
| 5~11 | 처참한 대실패 | 대실패 (실패 비용 + 후유증) |
| 1~4 | 후유증을 남긴 대실패 | 대실패 (실패 비용 + 후유증) |

**난수는 시드 고정 RNG(mulberry32)로 애니메이션 전에 확정**하고 `state.rng`에 저장합니다. 화면 연출은 이미 정해진 결과를 보여 줄 뿐이라 같은 시드는 끝까지 같은 게임이 됩니다(리플레이 가능). `pnpm test`의 "같은 시드 리플레이" 테스트가 이를 검증합니다.

## 조작과 시스템

- **스와이프 카드** — 카드 앞면(일러스트·제목·본문)을 왼쪽으로 밀면 선택지 A, 오른쪽이면 B, 선택지가 3개인 카드는 위로 밀어 C. 임계 거리를 넘기지 못하면 제자리로 돌아옵니다. 끄는 동안(버튼에 마우스를 올리거나 포커스해도) 그 선택지가 건드리는 게이지·자원 옆에 **점**이 뜨고, 점 크기로 대략의 규모만 보여 줍니다. 버튼과 키보드(← → ↑)도 그대로 쓰며, `prefers-reduced-motion`이면 회전·날아가기·전환 애니메이션을 끕니다.
- **첫 3턴 온보딩** — 1턴에 게이지 4개 → 5d20 판정과 등급 → 감염도 구간을 말풍선으로 안내하고, 2턴에 행동권, 3턴에 계절 보정을 한 번 더 짚습니다. 건너뛰기 / 다시 보지 않기.
- **지속 법령** (Frostpunk·Democracy 참고) — 세력마다 5개. 행동권 1개로 공포하거나 철회하고, 동시에 3개까지 유지합니다. 공포 중에는 매 계절 종료 결산에서 **유지비를 빼고 효과와 진노(도덕적 대가)를 적용**하며, 유지비를 못 내거나 해제 조건(예: 민심 15 이하)이 맞으면 저절로 폐지됩니다. 대시보드에 아이콘으로 표시됩니다.
- **연쇄 사건** (Reigns 참고) — 선택지의 `followUp: { cardId, afterTurns }`가 N턴 뒤 후속 카드를 예약합니다. 기존 카드 17쌍이 연결돼 있고, 후속 카드는 이전 판정이 실패 이하면 더 나쁜 상황·선택지로, 대성공 계열이면(일부 카드) 더 나은 선택지로 바뀝니다. 같은 연쇄는 한 판에 한 번만 나옵니다.
- **확산 지도와 소식** (Plague Inc. 참고) — 대시보드의 대륙 지도(아르칸달·아이루스·라벤 폐허)는 감염도가 높을수록 역병색이 진해집니다. 계절이 끝나면 AI 세력의 움직임을 "소식" 3줄 이내로 요약합니다.
- **난이도 3단계** — 보통 / 어려움 / 지옥. 기본 확산량, 늘어나는 진노, AI 부두교 압박에 배율을 겁니다(부두교 플레이 시에는 AI 왕국의 방역·방벽·연구에).
- **엔딩 컬렉션** — 승리·패배·생존 유형마다 고유 문구를 가진 엔딩 22종. 달성 기록(횟수·최고 난이도)은 IndexedDB에 저장돼 타이틀에 표시됩니다. 엔딩 화면에는 연대기를 요약한 **맞춤 후기 1~2문장**과 **시드 공유 링크**가 나옵니다.

## 밸런스 (세력당 1000회 자동 플레이, 휴리스틱 정책)

| 세력 | 보통 승률 | 평균 턴 | 어려움 | 지옥 |
|---|---|---|---|---|
| 아르칸달 | 32.3% | 9.4 | 22.4% | 12.9% |
| 아이루스 | 32.6% | 31.5 | 20.9% | 7.5% |
| 부두교 | 34.4% | 28.6 | 16.1% | 6.3% |

보통 난이도에서 목표였던 30~45% 승률 안에 세 세력 모두 들어옵니다. 자동 플레이 봇은 세력별로 법령 2개를 공포하고 연쇄 사건도 그대로 겪는 "그럭저럭 합리적인" 정책이라, 사람이 직접 하면 결과가 달라질 수 있습니다. 아르칸달은 초반 민심 붕괴가 잦은 고위험 세력으로 설계됐습니다.

## 가정 (기획서·요청서에 없어 제가 정한 결정)

- **능력치 보정** = (게이지 − 50) ÷ 5 (−10 ~ +10).
- **은닉(부두교)** 은 높을수록 안전한 게이지이며, 0이 되면 대토벌로 패배합니다.
- **효과 배율** 적용 규칙: 이로운 효과 ×배율, 해로운 효과 ×(2−배율)[0.4~1.7], 자원 비용(실링·전략 자원·식량·먹이 감소)은 고정, 부두교 확산 행동의 은닉 대가는 `withSuccess`로 성공할수록 더 깎입니다.
- **공통 카드 게이지 매핑**: 부두교에서 민심/질서/재정/정통성 → 신앙/제어/제물/은닉(정통성↔은닉은 부호 반전).
- **인구 손실 지연**: 잠복 1턴 → 발병 1턴 → 구울화. 인구 손실은 2계절 전 감염도를 기준으로 계산합니다.
- **기본 확산** = 1.5 + 감염도×0.04 (아르칸달 +1 후 방벽으로 감소, 부두교 제어<40 +2, 중립지는 별도 공식).
- **중립지(라벤 폐허 포함)** 감염도 시작 40. CI = (아르칸달 + 아이루스 + 중립지) ÷ 3.
- **진노 단계** 30/60/90/100 → 생산 ×0.95/0.85/0.7/0.5, 100은 모든 판정 −5이며 되돌릴 수 없음.
- **동맹**: 관계 80에서 체결(부두교는 구울 공인 협정). 아르칸달 외교 판정 −10.
- **행동권**: 미사용분을 다음 턴에 이월, 최대 3.
- **AI 부두교**(부두교를 플레이하지 않을 때): 매 턴 세력 규모에 비례해 대상 지역 감염도 +2~4(시간이 갈수록 증가). 플레이어가 부두교면 아르칸달·아이루스 AI가 방벽·연구를 진척시키며 경쟁합니다.
- 카드 데이터는 `author/`의 파이썬 DSL로 초안을 만들고(`content.json` 생성), 밸런스 조정 수치는 `content.json`에 직접 반영했습니다.
- 일러스트는 외부 이미지 없이 인라인 SVG 심볼 33종(기획서의 20종 이상 요건 충족)으로, 세력 2톤 + 금색 포인트의 플랫 벡터입니다.
- **후유증 기준**: 개선 요청서에는 "27 이하"로 적혀 있었지만 현재 코드(`grades.json`의 `aftermathAtOrBelow`)는 **17 이하**라 문서를 코드에 맞췄습니다. 실패 비용 기준(40 미만)은 요청서와 코드가 같습니다.
- **밸런스 재조정**: 15단계 판정 도입 커밋 직후 승률이 47.6/65.2/50.0%로 범위를 벗어나 있어 아이루스 연구 효율(0.3→0.27), 아르칸달 방벽 건설(+7→+6), 부두교 플레이 시 AI 방역 가산(1.6→1.7)을 조정했습니다.
- **스와이프**: 끌기 영역은 카드 앞면뿐이고 선택지 목록은 스크롤·클릭용으로 남겼습니다(모바일 세로 스크롤과 충돌 방지). 확정 임계 거리는 카드 너비의 28%(90~150px). 점 크기는 |효과| 4 이하/10 이하/그 이상의 3단계(인구·병력은 ×10로 환산), `onFail` 효과도 "영향 있음"에 넣었습니다. 자원이 모자란 선택지는 밀어도 확정되지 않습니다.
- **온보딩**: "첫 턴 안내 3종"과 "첫 3턴 온보딩"을 함께 만족하도록 1턴에 3단계, 2·3턴에 한 장씩 띄웁니다. "다시 보지 않기"는 브라우저 `localStorage`에 저장합니다.
- **법령**: 공포·철회는 주사위 판정 없이 확정되고, 매 턴 효과는 배율 없이 그대로 적용합니다. 종료 결산에서 생산 뒤에 처리(유지비 → 효과·진노 → 해제 조건)하며, 유지비를 못 내면 그 계절 효과 없이 폐지됩니다. 공포 중인 법령은 `decree:<id>` 플래그가 붙어 카드 조건에 쓸 수 있습니다. 철회 후 같은 법령을 다시 공포할 수 있습니다.
- **연쇄 사건**: 후속 카드는 새 카드가 아니라 기존 카드에 `branches`(이전 등급별 갈래)를 붙여 재사용합니다. 실패 계열(최종값 40 미만)은 나쁜 갈래, 대성공 계열은 좋은 갈래(7쌍에만), 그 밖은 원래 카드. 후속 카드는 자기 조건·계절을 무시하고 세 번째 사건 칸(고정 사건 턴이면 추가 칸)으로 나오며, 예약·사용된 후속 카드는 무작위 뽑기에서 빠집니다.
- **소식**: 문구 선택에 난수를 쓰지 않고(턴 번호로 순환) 기존 AI 난수 호출 순서를 그대로 둬, 소식 개선이 밸런스를 바꾸지 않습니다.
- **난이도**: 벤치마크(Plague Inc.)는 4단계지만 요청대로 3단계로 했습니다. 어려움/지옥 = 확산 ×1.2/×1.45, 늘어나는 진노 ×1.25/×1.5, AI 부두교 압박 ×1.3/×1.6. 부두교는 AI 방역에 매우 민감해(같은 배율이면 승률 0%) AI 왕국 방역 ×1.01/×1.02, 방벽·연구 속도 ×1.1/×1.15를 따로 씁니다. 30~45% 목표는 보통 난이도 기준입니다.
- **엔딩**: 기존 승패 판정을 그대로 두고 각 결말에 고유 id·문구를 붙였습니다(게이지 붕괴는 게이지마다 다른 문구). 달성 기록은 엔딩 화면에 들어갈 때 판마다 한 번 남깁니다.
- **시드 공유 링크**: 요청의 `?seed=` 외에 난이도 `d`와 세력 `f`도 넣어, 링크를 연 사람이 같은 판을 바로 시작할 수 있게 했습니다.
- **저장 호환**: 저장 형식이 v3로 바뀌었고, 이전 저장은 `migrateState`가 빠진 필드(법령·연쇄·난이도·판정 기록)를 기본값으로 채워 이어 갑니다.
- 웹 앱에도 vitest를 켜서 스와이프 판정·온보딩·지도 색·공유 링크 같은 순수 함수를 테스트합니다.
